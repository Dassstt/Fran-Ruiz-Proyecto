# Carpintería y Estructuras Metálicas Ruiz

Página web corporativa de **Ruiz — Carpintería y Estructuras Metálicas**, empresa ubicada en el Polígono Industrial de Álora (Málaga).

## Descripción

Sitio web estático de una página (single-page) con las siguientes secciones:

- **Hero** — Imagen destacada con CTA principal
- **Nosotros** — Descripción de la empresa y estadísticas
- **Servicios** — 3 líneas: Barandillas/Cerramientos, Techos/Pérgolas, Escaleras metálicas
- **Proyectos** — Galería de trabajos reales
- **Proceso** — Cómo trabaja el equipo
- **Contacto** — Formulario, teléfono, email, WhatsApp y dirección

## Tecnología

- HTML5 + CSS3 + JavaScript vanilla
- Sin frameworks ni dependencias externas
- Imágenes embebidas en base64 (archivo autónomo)
- Google Fonts (Cormorant Garamond, Marcellus SC, Oswald, Archivo)

## Despliegue en Vercel

Este proyecto está configurado para desplegarse automáticamente en Vercel.
Cada push a `main` actualiza la web en producción.
